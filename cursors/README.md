# cursors/

The macOS Apple cursor theme, vendored so a fresh machine gets the pointer
with no network fetch and no AUR helper.

- Source: https://github.com/ful1e5/apple_cursor (v2.0.1, this copy)
- License: GPL-3.0, see `LICENSE` in this directory
- Layout: `macOS/` is the theme root (`index.theme`, `cursor.theme`,
  `cursors/`). `install.sh` copies it to `/usr/share/icons/macOS`.

To update: unpack a newer `macOS.tar.gz` release over `macOS/` and record
the version in this file.
